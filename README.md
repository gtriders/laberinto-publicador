# Laberinto Publicador

Aplicación web para crear, analizar, revisar y programar contenido de las marcas Adrià.

## Flujo principal

1. Subir una foto o un carrusel de hasta 10 imágenes.
2. Analizar el contenido con IA y revisar el texto generado.
3. Elegir una fecha futura y confirmar la programación.
4. Supervisar publicaciones pendientes y errores en la cola real.
5. Usar el Planificador de contenido para decidir qué publicar y qué fotografías producir.

## Planificador de contenido

El Planificador ayuda a mantener cada marca variada entre producto, historia, experiencia, proceso, educación y venta. Muestra ideas de contenido y misiones concretas de fotografía, permite marcar material ya producido o descartar ideas y utiliza recomendaciones de horario cuando están disponibles.

El calendario comercial puede incorporarse como apoyo editorial, pero no reemplaza al Planificador de contenido.
